# ミナト用PC 設定手順（ミナトを「参加者」として会議に入れる）

## できあがりの形
```
上司のPC（このアプリのサーバー）            ミナト用PC（2台目）
・会議に上司として参加                        ・会議に「ミナト」として参加
・マイク＝上司の声、会議の音＝部下の声を聞く    ・ステージ画面（キャラクター）を映す
・ミナトが話すタイミングを決める ──Wi-Fi──▶  ・ミナトの声を会議に流す
```
- 部下には、会議の中に「ミナト」という参加者が見え、ミナトの声が聞こえます
- 2台は**同じWi-Fi**につないでください

---

## 1. 上司のPC（最初に1回＋毎回の起動）
1. アプリを、ほかのパソコンから開ける形で起動します（ターミナルで）
   ```bash
   ./tools/start_lan.sh   # このリポジトリのフォルダで実行
   ```
   - 初回に「受け入れますか？（着信接続）」とmacOSが聞いてきたら「許可」を押します
   - この起動のしかたでも、ほかのパソコンから開けるのは「合言葉つきのステージ画面」だけです。設定や会話の記録には届きません
2. Chromeで `http://127.0.0.1:8001` を開き、「面談のかたち」の画面まで進みます
3. 「ミナトの声と姿」で **ミナト用PCで会議に参加** を選びます
4. 表示されたアドレス（`http://192.168.…/stage?key=…`）をコピーして、ミナト用PCに送ります（メモ・チャットなど）

## 2. ミナト用PC（最初に1回）
### 声を会議に流す準備（BlackHole：無料の仮想マイク）
1. BlackHole 2ch をインストールします（公式サイト <https://existential.audio/blackhole/> 、Homebrewなら `brew install blackhole-2ch`）
2. 「システム設定」→「サウンド」→「出力」を **BlackHole 2ch** にします
   - このPCのスピーカーからは音が出なくなります（ミナト専用のPCなので問題ありません）

> Windowsの場合は、VB-CABLE（無料）を入れ、出力を「CABLE Input」、会議アプリのマイクを「CABLE Output」にします。

## 3. ミナト用PC（毎回）
1. Chromeで、上司のPCで表示されたアドレスを開きます
2. 「**開始する（音を出せるようにする）**」を押します
   - 上司のPCの画面に「準備OK：ミナト用PCから話します」と出れば接続できています
   - 上司のPCで「ミナト用PCでテスト再生」を押すと、ミナトが「聞こえていますか？」と話します
3. 会議アプリで、名前を **ミナト** にして会議に参加します
4. 会議アプリの設定を次のようにします

   | 項目 | 設定 | 理由 |
   |---|---|---|
   | マイク | **BlackHole 2ch** | ミナトの声を会議に流す |
   | スピーカー | **内蔵スピーカー**（音量は0でよい） | 会議の音がBlackHoleに入ると、会議に戻ってハウリングする |
   | 雑音の抑制 | 「低」または「オフ」 | 合成音声が削られて聞き取りにくくなるのを防ぐ |

5. ミナトの姿を映します（どちらか）
   - **かんたん**：会議アプリの「画面を共有」で、ステージ画面のタブ（またはウィンドウ）を共有する。キーボードの **F** で全画面になります
   - **参加者らしく見せる**：OBS（無料）で「ウィンドウキャプチャ」にステージ画面を選び、「仮想カメラ開始」。会議アプリのカメラを **OBS Virtual Camera** にすると、ミナトが顔の枠に映ります

## 4. 上司のPC（毎回）
1. 「面談のかたち」で **オンライン会議** を選び、「会議の音を共有する」で会議のタブを共有します
2. 「ミナトを同席させて面談を開始」を押します。ミナトのあいさつがミナト用PCから流れます
3. Zoom連携を使う場合は、設定の「無視する表示名」に **ミナト** を入れておきます

## うまくいかない時
| 症状 | 対処 |
|---|---|
| 上司のPCに「ほかのパソコンから接続できない設定で起動しています」と出る | `./tools/start_lan.sh` で起動し直す |
| ミナト用PCでアドレスを開いても表示されない | 2台が同じWi-Fiか確認する。会社のWi-Fiは端末どうしの通信を禁止していることがあるので、スマホのテザリングや家庭用ルーターで試す。上司のPCのファイアウォールで「python」を許可する |
| 「つながりました。ミナト用PCで『開始する』を押してください」のまま | ミナト用PCで「開始する」を押す（ブラウザは一度クリックしないと音を出せない） |
| ミナトの声が会議で聞こえない | ミナト用PCの出力がBlackHole、会議アプリのマイクがBlackHoleになっているか確認。会議アプリのマイクのミュートを外す |
| ミナトの声がこだまする・ハウリングする | ミナト用PCの会議アプリのスピーカーを「内蔵スピーカー」にする（BlackHoleにしない） |
| ミナトの声が上司のPCで「部下」の発言として出る | 上司のPCで会議の音を共有しているか確認（ミナトが話している間は数えない仕組み）。続く場合は名札をクリックして直す |
| 合言葉を変えたい | 上司のPCの「合言葉を作り直す」を押し、ミナト用PCで新しいアドレスを開き直す |

## 動作の約束
- ミナト用PCがつながっていない・「開始する」が押されていない時は、上司のPCから話します（声が消えることはありません）
- ミナト用PCに届くのは「ミナトが話す文・吹き出し・上司への提案（設定で消せる）・表情」だけです。部下の特性、会話の記録、実名の対応表は送りません
