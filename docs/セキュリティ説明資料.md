# セキュリティ説明資料：1on1 介入キャラクターAI

協力企業の皆様に安心してご利用いただくための、データの取り扱いについてのご説明です。

---

## 1. データの流れ

```
マイク（＋オンライン会議モードでは会議の音）
   ─┬→ Chromeの音声認識で文字に変換 → テキストをこのPCのサーバーへ → このPC内で判定 → 結果を返却
    │                                                   └（設定でオンの場合のみ）Anthropicで確認
    └→ ブラウザ内で音量と声の特徴を計算 → 発話の区切り・上司か部下かを判定（外部送信なし）
```

- **音声→テキスト変換には Google Chrome の音声認識（Web Speech API）を使います。** Chrome はこの変換のために音声を外部のサーバーへ送って処理します。view viewの発話中も、人の声に気づくため認識を続けます。アプリ自身が音声を保存することはありません。
- **オンライン会議モードでは、会議の相手の声も Chrome の音声認識へ送られます。** 上司が自分のPCで会議に参加し、会議のタブの音声を共有した場合です。面談の前に、相手（部下）にもview viewが同席し文字起こしをすることを伝え、了承を得てください。
- **上司・部下の聞き分けと発話の区切りの検出は、ブラウザ内で行います。** 使うのは音量、声の高さ、声色を表す数値と、文字起こしの文が敬語かどうかだけです。声の登録は不要で、登録した場合も声の特徴の数値はブラウザのメモリにだけ置き、ページを閉じると消えます。
- **このアプリは、会議アプリのマイク設定を変えません。** マイクは自動音量調整を切って1回だけ開き、PC全体のマイク音量を書き換えないようにしています。
- **介入の判定は、既定ではこのPC内だけで行います。** 発言の内容を Anthropic へは送りません。

### Claude判定をオンにした場合

設定で「Claudeでも判定する」をオンにすると、**このPC内の判定で気になる言い方が見つかった上司の発言について**、次の内容を Anthropic へ送ります。

- 上司の発言（確定前の途中の文を含む場合があります。話者が上司と分かっているときのみ）
- 直近の会話 最大6発言（部下の発言を含みます）
- 部下の特性プロファイル（特性、受け取りやすい誤解、響きやすい問い）
- 介入の感度、キャラクター設定

話者に確信がない発言と、デモ会話は送りません。

## 2. 個人情報の保護

### 面談前に書く「伝えたいこと」と、傾向診断の答え
- 「今日伝えたいこと」「部下に持ち帰ってほしいこと」「面談の後どうなってほしいか」は、**このPCのメモリにだけ**置き、面談が終わると消えます。ログには書いた件数と、話題に出た件数（目安）だけを残します
- 「部下に持ち帰ってほしいこと」は、view viewの吹き出し（view view用PCの画面を含む）に表示されます。部下に見せてよい言葉で書いてください
- Claude判定をオンにした場合は、名前を置き換えたうえで、面談の状況と伝えたいことも判定の材料として送ります
- 傾向診断の答えと点数は、このPCの設定（config.json）に保存されます。部下本人が答える場合は、結果を部下にも見せられる前提で使ってください。診断ではなく、面談で受け止め方に配慮するための参考です

### 名前の置き換え
- 設定画面で **実名と置き換え名（Aさん等）の対応** を登録すると、Claudeへ送る前に置き換えます
- 置き換えは **登録した表記と完全に一致した部分だけ** が対象です。音声認識の表記ゆれ、未登録の名前、あだ名は置き換えられないため、送信内容に個人名が含まれないことまでは保証できません

### 画面上での確認
- 面談画面の「外部に送ったデータの確認」で、直近の判定について外部送信の有無と送信内容を確認できます

### 部下の特性の表示
- 既定では、面談画面とふりかえりに部下のタイプや傾向を表示しません
- 上司だけが画面を見ている場合に限り、設定で表示できます。上司向けの提案は画面に表示されるため、部下と同じ画面を見る運用や画面共有では、内容が部下にも見えます

### アクセスの制限
- サーバーは、このPCからのアクセスだけを受け付けます。Zoom連携のWebhookだけは例外で、署名を検証して受け付けます
- view view用PC（2台目）を使う時だけ、`tools/start_lan.sh`（`STAGE_LAN=1`）で起動します。この時も、同じネットワークのほかのパソコンから開けるのは **合言葉つきのステージ画面・その部品・声の取得・再生の報告だけ** です。設定・会話・判定・ログには届きません（送り元のアドレスで判定するため、名乗りを偽っても通りません）。合言葉の間違いが続くと一時的に締め出します
- view view用PCに送るのは、view viewが話す文・吹き出し・上司への提案（設定で消せる）・表情だけです。部下の特性や会話の記録は送りません

## 3. データの保存先

| データ | 保存先 | 外部送信 |
|---|---|---|
| 会話ログ | ローカルPC（logs/）。**既定では発言の原文を保存せず**、文字数と判定結果のみ | しない |
| 発言の原文 | 設定でオンにした場合のみ logs/ に保存 | しない |
| 話す／見送るの判断の記録 | ローカルPC（logs/）。発言の本文は含まない | しない |
| 音声の計測値（認識の速さ・区切り） | ローカルPC（logs/）。時間・件数・一致率のみで、発言の本文と読み上げた文は含まない | しない |
| 設定（性格プロファイル、実名の対応表等） | ローカルPC（config.json）に平文で保存 | Claude判定がオンの場合、プロファイルを送信 |
| 音声データ | **保存しない** | Chromeの文字変換のため送信される（オンライン会議モードでは相手の声も含む） |
| 声の特徴の数値 | **ブラウザのメモリのみ** | しない |
| 合成音声（VOICEVOX使用時） | このPC上で生成 | しない |
| Zoom連携時の文字起こし（参加者名つき） | Zoom（RTMS）からこのPCで受信 | Zoomから受信する（Claude判定がオンの場合は上記のとおり送信） |
| 判定に使うテキスト | このPCのメモリ | Claude判定がオンの場合のみ Anthropic へ送信 |

この変更より前に作成した logs/ のファイルには、発言の原文が含まれている場合があります。不要であれば削除してください。

## 4. Anthropic社のデータポリシー

Claude判定をオンにする場合は、送信データの利用と保持期間について、契約内容と Anthropic の最新のポリシーをご確認ください。判定の直後にデータが削除されるとは限りません。

- 詳細: https://www.anthropic.com/policies/privacy

## 5. 導入前にご確認いただきたいこと

1. **部下本人への説明と同意**：特性プロファイルは上司の回答から作られます。利用目的、記録の内容、断っても不利益がないこと、人事評価に使わないことを事前に説明する必要があります。法令上の扱いは、社内の法務または専門家にご確認ください
2. Claude判定を使うかどうかを、社内のルールに沿って決めてください
3. Claude判定を使う場合は、登場する人名を名前の置き換えに登録してください
4. 部下と同じ画面を見る場合や画面共有中は、「部下の特性を表示する」をオフのままにしてください
5. logs/ と config.json を、御社のセキュリティポリシーに従って管理・削除してください
